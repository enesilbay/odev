# PAÜFilm — Movie Showcase Website

A static movie showcase website built with plain **HTML, CSS and JavaScript**. It lists popular films as poster cards and gives every film its own detail page. It was created as a university web programming assignment.

## Features

- Poster grid with **26 films**, each linking to a detail page (plot, director and more)
- **Live search** that filters films as you type
- **Random movie suggestion** button ("Bana Bir Film Öner")
- **Dark mode** toggle, remembered across visits with `localStorage`
- Loading screen (preloader) and responsive layout
- No frameworks or build step

## Project Structure

```
├── index.html     # Home page with the film grid
├── style.css      # Styles including dark mode
├── script.js      # Search, random pick, theme toggle, preloader
├── detaylar/      # One detail page per film
├── afisler/       # Movie posters
└── images/        # Logo and site images
```

## Getting Started

No installation is needed. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/enesilbay/odev.git
cd odev
# open index.html in your browser
```
